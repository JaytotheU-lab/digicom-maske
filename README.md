# digicom-maske

Eingabemaske (Schritt 0) für die Account-Recherche von digicom)).

- `maske.js` enthält nur Fragen, Auswahlkacheln und Infotexte – **keine Kundendaten**.
- Kundendaten (Vorbelegung) werden nur im Chat übergeben und lokal im Browser eingesetzt.
- Die Maske sendet nichts ins Internet; „Recherche starten“ schreibt die Antworten nur in den Chat.
- Eingebunden wird immer eine feste Version (Git-Tag, z. B. `v1`). Änderungen werden erst mit neuem Tag und Anpassung im Skill wirksam.
